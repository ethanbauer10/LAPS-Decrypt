# LAPS-Decrypt
I solved the Sentinel lab on HackSmarter recently, during the lab I needed to decrypt a LAPS passwords so I wanted to make a more functional method.

```
[SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\LAPS;ADPasswordEncryptionPrincipal;;&;TRASK\R&D_Auditors]
```

This was the giveaway in the lab, my user was part of the `R&D_Auditors` group.

So this tool uses the dpapi-ng repo made by jborean93, so this will need to be installed prior to using the tool

```
python3 -m venv venv

source venv/bin/activate

pip3 install dpapi-ng

pip3 install dpapi-ng[kerberos]
```

In my personal opinion its worth setting this up in the python virtual environment to save messing with system packages

After setting up and activating the `venv` simply install `dpapi-ng` and the kerberos dependency if required

PLEASE NOTE: If using kerberos the tool will require a realm and a TGT for your user set as the `ADPasswordEncryptionPrincipal`

NetExec has options to do this seamlessly
